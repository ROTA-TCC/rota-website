# Rota - Website

Este é o repositório da landing page institucional do projeto Rota, desenvolvido com React, TypeScript e Vite. O site tem como objetivo apresentar e divulgar o aplicativo Rota, focado em soluções para o setor de saúde.

## Sobre o Projeto

O Rota Website funciona como a página de apresentação oficial do ecossistema. Desenvolvido para oferecer uma interface responsiva e performática, o site utiliza o framework Vite para garantir rapidez no carregamento e facilidade na manutenção.

O site está hospedado e disponível publicamente em: [https://rota-tcc.vercel.app](https://rota-tcc.vercel.app)

## Stack Tecnológica

- **Framework:** React 19
- **Linguagem:** TypeScript
- **Ferramentas de Build:** Vite
- **Estilização:** Tailwind CSS
- **Animações:** Motion
- **Ícones:** Lucide React
## Configuração e Execução Local

### Pré-requisitos
- Node.js (versão 18 ou superior recomendada).
- npm ou pnpm.

### Passo a passo
1. **Instalação de dependências:**
   No diretório raiz do projeto, execute:
   ```bash
   npm install
   ```

2. **Iniciar em modo de desenvolvimento:**
   O comando abaixo inicia o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. **Build para produção:**
   Para gerar os arquivos estáticos de produção na pasta `dist`:
   ```bash
   npm run build
   ```

## Scripts Disponíveis

- `npm run dev`: Inicia o servidor de desenvolvimento.
- `npm run build`: Compila o projeto para produção.
- `npm run preview`: Pré-visualiza o build localmente.
- `npm run lint`: Executa a verificação de tipos com TypeScript (`tsc`).
- `npm run clean`: Remove a pasta de build (`dist`).
